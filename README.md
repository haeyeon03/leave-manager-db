# 🛫 쉬자GO - 휴가 통합 관리 시스템

## 📌 프로젝트 개요

- **프로젝트명:** 쉬자GO - 휴가 통합 관리 시스템  
- **개발 기간:** 2025-06-09 ~ 2025-06-15  
- **개발자:** 이해연

### 🎯 목적

쉬자GO는 조직 내 모든 휴가 관련 정보를 통합하여 관리하고, 직원과 관리자가 쉽고 빠르게 휴가를 신청, 승인, 조회할 수 있도록 지원하는 시스템이다.

- 휴가 신청 및 승인 절차의 **효율성 향상**  
- 휴가 이력 및 잔여 휴가 관리의 **체계화**  
- 인사 관리의 **정확성과 투명성 확보**

## 📝 요구사항 정의서 및 기능 명세

### 👤 사용자 페이지

- 언제 어디서든 자신의 휴가 상태 확인 가능  
- 간편한 휴가 신청 기능  
- 신청한 휴가의 **승인 여부 및 상태** 실시간 확인  
- 잔여 휴가 일수 및 사용 내역 조회  

### 🧑‍💼 관리자 페이지

- 직원 휴가 신청 현황 조회  
- 휴가 신청에 대한 **승인 또는 반려** 처리 가능  
- 직원별 휴가 사용 이력 및 잔여 일수 실시간 조회  

---

## 🧩 아키텍처 및 설계 패턴

- MVC (Model-View-Controller) 패턴 적용  
- Model: Oracle DB 연동 및 데이터 처리  
- View: 사용자/관리자 UI 화면  
- Controller: 사용자 요청 처리 및 Model-View 간 데이터 흐름 중재  

MVC 패턴으로 유지보수 용이성과 역할 분리 통한 효율적 개발 달성  

---
## 🧪 데이터 관리 방식

- Oracle DB를 연동하여 데이터 저장 및 조회  
- MVC 패턴 내 Model에서 DB와 직접 연결하여 데이터 처리  
- 초기 개발 단계에서는 Java 입출력 스트림(File I/O)을 활용한 임시 데이터 관리도 진행함

## 🗃️ DB 테이블 명세서

### 사원 테이블 (EMPLOYEE_TBL)

| 컬럼명        | 한글명     | 데이터 타입 | 크기 | Null 허용 | 키  | 비고                   |
|---------------|------------|-------------|------|-----------|-----|------------------------|
| emp_no        | 사원번호   | INT         | -    | N         | PK  | 사원 번호              |
| password      | 비밀번호   | VARCHAR2    | 20   | N         |     | 비밀번호               |
| emp_name      | 이름       | VARCHAR2    | 10   | N         |     | 사원 이름              |
| position      | 직급       | VARCHAR2    | 10   | N         |     | 직급                   |
| birth_date    | 생년월일   | DATE        | -    | N         |     | 생년월일 (YYYY-MM-DD)  |
| hire_date     | 입사일     | DATE        | -    | N         |     | 입사일자 (YYYY-MM-DD)  |
| phone_number  | 전화번호   | VARCHAR2    | 20   | Y         |     | 전화번호               |
| is_admin      | 관리자 여부| CHAR(1)     | -    | N         |     | 관리자 여부 (Y/N)      |

---

### 사원별 연차 휴가 테이블 (EMPLOYEE_LEAVE_BALANCE_TBL)

| 컬럼명         | 한글명         | 데이터 타입 | 크기 | Null 허용 | 키  | 비고              |
|----------------|----------------|-------------|------|-----------|-----|-------------------|
| emp_no         | 사원 번호      | INT         | -    | N         | PK  | 사원 번호         |
| year           | 연차 연도      | INT         | -    | N         | PK  | 연차 연도 (YYYY)  |
| remaining_days | 잔여 휴가 일수 | INT         | -    | N         |     | 남은 휴가 일수    |

---

### 휴가 신청 테이블 (LEAVE_REQUEST_TBL)

| 컬럼명     | 한글명         | 데이터 타입 | 크기 | Null 허용 | 키  | 비고                      |
|------------|----------------|-------------|------|-----------|-----|---------------------------|
| req_no     | 휴가 신청 번호 | INT         | -    | N         | PK  | 휴가 신청 번호            |
| leave_type | 휴가 유형      | VARCHAR2    | 10   | N         |     | 휴가 유형 (연차, 병가 등) |
| start_date | 시작일자       | DATE        | -    | N         |     | 휴가 시작일 (YYYY-MM-DD)  |
| end_date   | 종료일자       | DATE        | -    | N         |     | 휴가 종료일 (YYYY-MM-DD)  |
| reason     | 사유           | VARCHAR2    | 100  | N         |     | 휴가 사유                 |
| status     | 상태           | VARCHAR2    | 10   | N         |     | 결재 상태 (대기, 승인, 반려) |
| emp_no     | 사원 번호      | INT         | -    | N         | FK  | 사원 번호                 |
